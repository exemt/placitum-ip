# Установка

[English](INSTALL.md) · Русский

Инспектор не слушает сеть: он подписчик очереди на шине. Адрес и сервис ему не нужны, и добавление
копии не трогает ни узел защиты, ни конфигурацию. Обычно его ставит `placitum-core`.

## Что нужно рядом

| Компонент | Обязателен | Зачем |
| --- | --- | --- |
| NATS | да | очередь `waf.req.ip`, аудит, журнал, поколение профилей, уведомления живых наборов |
| Внутренний Redis | да | тела списков поколения, пакеты и снапшоты живых наборов |
| Контроллер | да | шлёт профили поколением |
| `keeper` | при живых наборах | держит их состав; инспектор его зеркалит и отправляет туда записи `list` |
| `geo` | при записях `net`, `net_all` и `asn` | анонсы и номер системы по адресу |

Обменник инспектору не нужен: адрес приезжает в сообщении.

## Настройки

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `NATS_URL` | `nats://127.0.0.1:4222` | шина; несколько адресов — через запятую |
| `REDIS_INTERNAL_URL` | из `inspector.conf` | внутренний Redis; отката на обменник нет |
| `WAF_IP_SUBJECT` | `waf.req.ip` | подписка; должна совпадать с `subject=` в объявлении инспектора |
| `WAF_IP_NAME` | `ip` | имя в реестре инспекторов и в кадре присутствия |
| `WAF_IP_QUEUE` | имя | очередь шины |
| `WAF_IP_POLICY` | `./policy`; в образе `/app/policy` | дерево политики до первого поколения |
| `WAF_IP_GEO` | `./data/geo`; в образе `/app/data/geo` | диапазоны стран до первого поколения; в образе пусто, страны приезжают поколением |
| `WAF_IP_DATA` | пусто; в образе `/app/state` | куда раскатка кладёт применённое поколение; пусто — поколения выключены |
| `WAF_IP_RELOAD_EVERY` | `1s` | как часто проверять файлы политики; `SIGHUP` перечитывает сразу |
| `WAF_IP_CONF` | `inspector.conf` в рабочем каталоге, затем `/app/inspector.conf` | очередь и адрес Redis |
| `WAF_IP_WORKERS` | число ядер | воркеры проверки |
| `WAF_IP_QUEUE_DEPTH`, `WAF_IP_QUEUE_FULL`, `WAF_IP_QUEUE_EXPAND` | `256`, `drop`, `off` | очередь и поведение при переполнении; то же через `inspector.conf` |
| `WAF_IP_RESERVE_MS`, `WAF_IP_MIN_BUDGET_MS` | `1`, `1` | запас на ответ и минимальный бюджет, ниже которого проверка не начинается |
| `WAF_IP_VERSIONS` | `2` | версии схемы сообщения, которые процесс принимает |
| `WAF_IP_GEO_ADDR` | пусто | кодер гео (`host:port`); пусто — записи `net`, `net_all` и `asn` отвечают `error` |
| `WAF_IP_GEO_TIMEOUT`, `WAF_IP_GEO_NEG_MAX` | `500ms`, `0` | ожидание кодера в бюджете сообщения и потолок отрицательного кэша (`0` — миллион записей) |
| `WAF_IP_LOG` | `info` | стартовый уровень журнала; живьём его переставляет панель |
| `WAF_HEARTBEAT_EVERY` | `4s` | период кадра присутствия |
| `WAF_LOG_SHIP` | `on` | уезжает ли журнал процесса на шину; `off` оставляет только stdout |

## Docker Compose

```yaml
services:
  inspector-ip:
    image: placitum/ip
    scale: 4
    environment:
      NATS_URL: nats://nats:4222
      REDIS_INTERNAL_URL: redis://redis-internal:6379
      WAF_IP_SUBJECT: waf.req.ip
      WAF_IP_NAME: ip
      WAF_IP_GEO_ADDR: geo:50051
    depends_on: [nats, redis-internal]
```

Копий столько, сколько нужно: очередь шины раздаёт сообщения между ними, координации между копиями
нет.

## Проверка

Своего порта у инспектора нет, поэтому проверяют его тем же путём, что и работает, — сообщением по
шине:

```sh
docker exec <контейнер> ip-probe --quiet --timeout 1s
```

`HEALTHCHECK` образа делает ровно это. В журнале при здоровом старте: подключение к шине, имя
очереди, загруженные профили, число воркеров. Дальше каждые четыре секунды уходит кадр присутствия, и
в нём же состояние живых наборов.

## Грабли

- **Пустой `WAF_IP_GEO_ADDR`** — записи сети и системы отвечают `error`, а не пропускают молча: «не
  смог проверить» и «проверил, всё чисто» — разные ответы.
- **Живые наборы приходят не с поколением.** Поколение везёт профили, состав держит keeper. Сошлось
  поколение — ещё не значит, что состав доехал; это видно в кадре присутствия.
- **Копия не хранит состояния.** После перезапуска она заново тянет снапшоты живых наборов; пока они
  греются, правила по спискам отвечают по тому, что уже приехало.
- **Каталоги политики и гео обязаны существовать.** Опечатка в `WAF_IP_POLICY` или `WAF_IP_GEO`
  роняет старт, а не всплывает на первом сообщении.
